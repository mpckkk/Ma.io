#### **Basic Completion with GPT-4** ####

Let’s begin with a basic example of generating a response using gpt-4. We provide a system message and a user prompt and examine how the model responds.

```typescript
response = openai.ChatCompletion.create(
    model="gpt-4",
    messages=[
        {"role": "system", "content": "You are a helpful scientific assistant."},
        {"role": "user", "content": "Explain the importance of dimensionality reduction in single-cell RNA-seq analysis."}
    ],
    temperature=0.7,
    max_tokens=300,
)
print(response['choices'][0]['message']['content'])
```

This will return a well-structured explanation targeted to the scientific audience, useful for writing educational content or technical documentation.

#### **Few-shot Prompting for Structured Output** ####

To guide the model toward producing structured answers, you can provide a few examples. Here we instruct the model to respond to gene function queries in a consistent format.

```typescript
messages = [
    {"role": "system", "content": "You are a scientific assistant who answers gene-related questions with structured responses."},
    {"role": "user", "content": "Gene: TP53\nWhat does it do?"},
    {"role": "assistant", "content": "Function: Tumor suppressor gene involved in preventing cancer.\nPathways: Apoptosis, DNA repair, cell cycle arrest.\nAliases: P53, BCC7."},
    {"role": "user", "content": "Gene: BRCA1\nWhat does it do?"}
]

response = openai.ChatCompletion.create(
    model="gpt-4",
    messages=messages,
    temperature=0.3,
    max_tokens=200,
)
print(response['choices'][0]['message']['content'])
```

#### **Tip: Use temperature and max_tokens wisely** ####
	•	temperature: Controls randomness. Use lower values (0.2–0.4) for precision and higher (0.7–1.0) for creativity.


	•	max_tokens: Adjust depending on how long you expect the response to be.
